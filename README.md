# CrateSnap Audit

A single-page app for cataloging vinyl records. It saves records in the browser and can sync to Google Drive and Sheets.

Open `index.html` in a browser, or use the GitHub Pages site for this repo.

No keys are stored in the code. Google settings (client ID, Drive folder, Apps Script webhook) are typed into the app's "Drive & Sheets" panel and stay in that browser's localStorage.
